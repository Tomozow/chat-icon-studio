# Chat Icon Studio

Twitch のチャット欄に近い見た目で、エモート・バッジ・チャンネルポイント画像をプレビューし、公式サイズの画像ファイルに書き出す **Windows 向け** Tauri 2 アプリです。

セッション中のみ保持します。サーバーへはアップロードしません。

## GitHub Pages

公開 URL（デプロイ後）: https://Tomozow.github.io/chat-icon-studio/

1. Settings → Pages → Source: **GitHub Actions**
2. `main` にソースを push する（または Actions で GitHub Pages を手動実行）
3. Windows インストーラは Releases に `Chat Icon Studio_0.1.0_x64-setup.exe` を添付
